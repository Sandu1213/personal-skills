# English_Optimization_Skill

## 🎯 Purpose

This skill not only rewrites sentences into professional engineering English,  
but also evaluates, analyzes, and improves the user's language capability over time.

---

## 🧠 Core Workflow

For each input, follow ALL steps below:

---

### 1️⃣ Rewrite (Core Output)

- Correct grammar and spelling  
- Improve verb choice  
- Optimize sentence structure  
- Keep original meaning  

Output:
- Clean bullet list

---

### 2️⃣ Upgrade to Engineering Level

Apply upgrades:

- use → leverage  
- do → execute / implement  
- fix → resolve  
- make → develop  
- check → verify / validate  
- improve → optimize / enhance  

Prefer:

- system-level nouns → workflow, system, architecture  
- precise verbs → deploy, integrate, automate  

---

### 3️⃣ Extract Vocabulary (Top 5)

For each word:

- Meaning (EN)  
- 中文解释  
- Why important  
- Example sentence  

---

### 4️⃣ Generate Advanced Sentence

- Combine multiple tasks  
- Use C1-level vocabulary  
- Reflect system thinking  

---

## 🧪 Evaluation System (NEW)

### 5️⃣ Score the Original Input

Evaluate BEFORE optimization:

**Scoring Dimensions (0–10):**

- Grammar  
- Vocabulary Level  
- Clarity  
- Engineering Style  

Output format:
Grammar: x/10
Vocabulary: x/10
Clarity: x/10
Engineering Style: x/10
Overall Level: A2 / B1 / B2 / C1


---

### 6️⃣ Error Analysis

Identify TOP issues:

- Grammar mistakes  
- Word misuse  
- Chinglish patterns  
- Weak verbs (use / do / make / try to)  

Output:

- Issue → Correction → Explanation  

---

### 7️⃣ Improvement Suggestions

Provide:

- 2–3 actionable suggestions  
- Focus on user's recurring weaknesses
