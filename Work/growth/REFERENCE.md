# Growth Tracker 参考说明

## 指标定义与评分标准

### 🏥 健康板块

| 指标 | 说明 | 理想范围 |
|------|------|----------|
| 睡眠时长 | 实际睡眠小时数 | 7-9 小时 |
| 睡眠质量 | 主观评分 1-5 | ≥ 4 |
| 运动时长 | 当日运动总分钟 | ≥ 30 分钟 |
| 运动类型 | 有氧/力量/柔韧 | 每周至少2种 |
| 饮食评分 | 均衡程度 1-5 | ≥ 3 |
| 饮水量 | 杯数（约250ml/杯） | ≥ 8 杯 |
| 体重 | 单位 kg | 根据个人目标 |
| 身体状态 | 精力充沛/一般/疲惫 | 精力充沛 |

### 📚 英语学习板块

| 指标 | 说明 | 建议目标 |
|------|------|----------|
| 新词汇数 | 当日新学单词量 | ≥ 10 个/天 |
| 阅读时长 | 英文阅读分钟数 | ≥ 20 分钟 |
| 阅读材料 | 文章/书籍/新闻来源 | 记录标题即可 |
| 听力练习 | 播客/视频/对话 分钟数 | ≥ 15 分钟 |
| 口语练习 | 跟读/对话/录音 分钟数 | ≥ 10 分钟 |
| 写作练习 | 日记/作文/翻译 字数 | 选做 |
| 难点记录 | 语法/发音/理解难点 | 每日至少1条 |

### 💰 财务板块

| 指标 | 说明 | 备注 |
|------|------|------|
| 总收入 | 当日所有收入 | 工资/副业/利息等 |
| 总支出 | 当日所有支出 | 按分类记录 |
| 支出分类 | 餐饮/交通/娱乐/购物/教育/医疗/其他 | 可自定义 |
| 投资动态 | 基金/股票/加密货币等 | 记录操作与收益 |
| 储蓄目标进度 | 距离目标金额的百分比 | 月度更新 |
| 净收支 | 收入 - 支出 | 自动计算 |

## 报告对比规则

### 周报对比
- 对比范围：本周 vs 上周（周一至周日）
- 变化标记：`↑ 提升` / `↓ 下降` / `→ 持平`（变化 < 5% 视为持平）

### 月报对比
- 对比范围：本月 vs 上月
- 额外增加：月度趋势折线描述、本月亮点与待改进项

### 评分汇总规则
- 健康综合分 = (睡眠质量×30% + 运动完成率×30% + 饮食评分×20% + 身体状态×20%) × 20
- 英语学习分 = (词汇完成率×25% + 阅读完成率×25% + 听力完成率×25% + 口语完成率×25%) × 20
- 财务健康分 = 基于净储蓄率和目标完成度评估（满分100）
